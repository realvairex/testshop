# Veröffentlichte Audit-Seite

`petworld-audit.html` ist die Quelldatei der geteilten Audit-Seite.

**URL:** https://claude.ai/code/artifact/eb8007e1-4516-470e-94ce-376c38daacdb

## Aktualisieren

Datei bearbeiten, dann mit dem `Artifact`-Werkzeug veröffentlichen — **immer mit
`url`**, sonst entsteht eine zweite Seite statt einer Aktualisierung:

```
Artifact(
  file_path = "docs/artefakt/petworld-audit.html",
  url       = "https://claude.ai/code/artifact/eb8007e1-4516-470e-94ce-376c38daacdb",
  favicon   = "🐾"
)
```

## Warum die Datei hier liegt

Sie lag ursprünglich im sitzungseigenen Scratchpad und wäre mit dem Chat verloren
gegangen — eine neue Session hätte die Seite nicht mehr aktualisieren können.

## Wichtig

Die Seite ist **teilbar** und wird gelesen. Sobald sich Zahlen oder Befunde ändern,
gehört sie mit aktualisiert. Das steht als fester Punkt im Ablauf `ende-petworld`.
